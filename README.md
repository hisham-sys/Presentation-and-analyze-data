# 🎓 Student Performance Dashboard

لوحة تحكم تفاعلية لتحليل أداء الطلاب في الاختبارات. المشروع جزء من مقرر **Data Analysis and Presentation with Python** - كلية الهندسة - برنامج AIE - جامعة المنصورة - ربيع 2026.

---

## 📋 الأسئلة التحليلية

- كيف تتوزع درجات الطلاب في المواد الثلاث (الرياضيات، القراءة، الكتابة)؟
- هل يوجد فرق بين أداء الذكور والإناث في الرياضيات؟
- هل تؤثر الدورة التحضيرية على الدرجات؟
- ما العلاقة بين المواد الدراسية المختلفة؟

---

## 🛠️ الأدوات والتقنيات

| التقنية | الاستخدام |
|---------|-----------|
| Python | لغة البرمجة الأساسية |
| Pandas | تحليل وتنظيف البيانات |
| Plotly | رسوم بيانية تفاعلية |
| Streamlit | بناء لوحة التحكم التفاعلية |

---

## 📊 مميزات لوحة التحكم

- 🎛️ فلاتر جانبية للتصفية (الجنس، العرق، الدورة التحضيرية، تعليم الوالدين، مستوى الدرجات)
- 📈 4 أنواع مختلفة من الرسوم البيانية التفاعلية
- 📊 مؤشرات إحصائية (عدد الطلاب، المتوسط، الأعلى، الأقل)
- 📥 إمكانية تحميل البيانات المصفاة بصيغة CSV
